This is a code of my 3d puzzle game. In this game you have to complete 20 levels.
On each level you have record your own movements and use them in the next rounds to complete a level.
In the game I also implemented save system, key rebindings, several languages.
However optimization of the game is bad as I used too many vertices on tree leaves and grass.
I did not uploaded here a whole unity project because I used Unity version control for that.
